# Fotometro_ESP32_Supermini

Documentação contendo projeto da PCB, código do arduino, código do aplicativo, aplicativo para android em .apk e arquivos stl do dispositivo. 

A montagem das peças dos arquivos tampa_cubeta e tampa deve ser feita usando um imã de 4x2 mm, a fim de serem conectadas de maneira facil.

As placas pcb foram feitas na china pela jlcbcb. Elas foram fixadas na base usando dupla face.

O projeto foi desenvolvido por Kaique de Sotti Silva e Flavio Camacho.
